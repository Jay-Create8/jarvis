# J.A.R.V.I.S. – persönlicher KI-Assistent (PWA)

Holo-Interface mit 3D, Sprache, Handsteuerung, Dateien, Kalender, Wächtern und optional Server (Telefon, Fernsteuerung).
Gehirn: Claude (Anthropic) – **dein eigener API-Key wird nur auf deinem Gerät gespeichert** (optional mit PIN verschlüsselt).
In diesem Repository liegen **keine Zugangsdaten**.

## Benutzen
App öffnen: `https://<dein-github-name>.github.io/jarvis/` → im Browser-Menü „Zum Startbildschirm hinzufügen“ →
Einstellungen → Anthropic API-Key eintragen.
